01 • PROPÓSITO

O problema e a solução

Antes do Spawnly

  • Seeds espalhadas por diferentes páginas.
  • Comparação manual de edição, versão e estruturas.
  • Demora para achar um mundo com as características desejadas.

Com o Spawnly

  • Questionário com critérios claros.
  • Catálogo de seeds cadastradas.
  • Resultados ordenados por compatibilidade.
Objetivo: transformar as preferências do jogador em recomendações relevantes.

07 • DADOS DE ENTRADA

Cadastros e validação

Informações trabalhadas

  • Usuário: nome, edição, versão.
  • Preferências: biomas, estruturas e estilos.
  • Seed: código, versão, biomas e estruturas.
  • Extras: dificuldade, descrição e spawn.

Regras no backend

  • Validação de campos e formatos.
  • Conferência de IDs e catálogos.
  • Detecção de sementes duplicadas por versão.
  • Chave para alteração administrativa de seeds.
Limitação: os tokens atuais servem ao protótipo acadêmico; não são autenticação completa para dados pessoais sensíveis.

10 • CÓDIGO REAL

Como a recomendação é calculada

● ● ●backend/services/recomendacao.js
const pontosBioma = preferencias.biomas.length === 0
  ? 0
  : (biomasEncontrados.length /
     preferencias.biomas.length) * 60;

const pontosEstruturas = preferencias.estruturas.length === 0
  ? 0
  : (estruturasEncontradas.length /
     preferencias.estruturas.length) * 40;

const pontuacao = Number(
  (pontosBioma + pontosEstruturas).toFixed(2)
);

O que acontece

  • Compara preferências e catálogo.
  • Transforma coincidências em pontos.
  • Soma e arredonda a pontuação.
  • Ordena as recomendações.

Não é IA: é uma regra matemática determinística.
