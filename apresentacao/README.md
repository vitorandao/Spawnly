# Apresentação HTML — Spawnly

Esta pasta contém uma apresentação de **18 slides** sobre o projeto acadêmico Spawnly, baseada nos arquivos atuais da branch principal e nas responsabilidades documentadas no README.

## Acessar

- **Apresentação on-line (projeto Vercel separado):** https://spawnly-slides-apresentacao-h30yybwts.vercel.app/
- **Aplicação real:** https://spawnly-six.vercel.app/

A apresentação está na branch `presentation/spawnly-html-completo-20261117`, isolada da branch `main`.

## Arquivos

- `index.html`: conteúdo e notas dos 18 slides.
- `style.css`: identidade visual responsiva, visual inspirado em pixels e impressão em paisagem.
- `app.js`: navegação, índice, notas, tela cheia e gestos de toque.

Não há dependências externas para executar os slides. Para abrir offline, baixe **os três arquivos** para uma mesma pasta e abra `index.html` no navegador.

## Controles

| Comando | Ação |
| --- | --- |
| Seta direita / espaço | Próximo slide |
| Seta esquerda | Slide anterior |
| Home / End | Primeiro / último slide |
| M ou botão ☷ | Índice de slides |
| N ou botão Notas | Texto para apresentar |
| F ou botão ⛶ | Tela cheia |
| Deslizar para os lados | Trocar slide no celular |
| Imprimir no navegador | Gerar páginas 16:9 |

## Conteúdo

Capa, problema, jornada, stack, frontend, arquitetura, CRUD, validações, catálogo, algoritmo, código, Cubiomes, banco original e armazenamento publicado, Vercel, testes, divisão da equipe, melhorias e encerramento.

### Precisões técnicas

- O backend original do repositório utiliza Express e MariaDB/MySQL.
- O site publicado em `spawnly-six.vercel.app` utiliza funções Vercel e Vercel Blob, não PostgreSQL.
- Os papéis de Nathaniel e Beatriz são sugestões ou não confirmados no README.
- O mapa exibido no slide é ilustrativo, não a geração exata da seed informada.

**Esta branch não altera a aplicação real.**
